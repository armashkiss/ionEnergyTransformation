## Публикация

```bash
cd ~/Загрузки
rm -rf ionEnergyTransformation
mkdir ionEnergyTransformation
unzip -o "ION_ENERGY_Transformation_Pages_v8.zip" -d ionEnergyTransformation
cd ionEnergyTransformation

git init
git branch -M main
git add .
git commit -m "Deploy full ION Energy transformation strategy"
git remote add origin git@github.com:armashkiss/ionEnergyTransformation.git
git push -u origin main --force
```

GitHub → Settings → Pages → Deploy from a branch → `main` → `/(root)`.

Mermaid-графы рендерятся через CDN.

## Исправление пустых страниц v11

Причина пустой печати была найдена: секции сайта используют анимационный класс `.reveal`.
До появления элемента на экране он имеет `opacity: 0`, а браузер печатал такие блоки как
занимающие место, но полностью прозрачные.

В v11:
- при печати все `.reveal` принудительно становятся видимыми;
- отключаются transform/animation/transition;
- снимаются унаследованные min-height, создававшие пустые листы;
- все execution-details раскрываются перед печатью;
- сохраняется светлая печатная тема v10;
- сохраняются светлые SVG диаграммы;
- сохраняется нижний колонтитул:
  `Автор: Проектный менеджер Нурмахан А.`
